# AURUM Player Interface

Демонстрационный адаптивный frontend игрового лобби и личного кабинета. Реальные ставки, платежи, вход у оператора и игровое ядро не подключены.

## Возможности

- Каталог с поиском, фильтрами, сортировкой, избранным и персональными подборками.
- Карточки игр с демонстрационными RTP, волатильностью и правилами.
- Кабинет с финансовой статистикой, графиком, лимитами и прозрачным бонусным прогрессом.
- Пауза и самоисключение как демонстрация пользовательского сценария.
- Верификация, статус выплаты, история операций и экспорт CSV.
- Локальные обращения в поддержку, FAQ и настройки уведомлений.
- Русская и английская локализация.
- PWA-манифест, установка и offline-кэш статических ресурсов.

## Данные и интеграции

Все игры, студии, люди и операции вымышлены. Избранное, лимиты, обращения и настройки сохраняются только в `localStorage` текущего браузера. Серверной синхронизации нет. Для реальной эксплуатации требуется сертифицированный B2B-провайдер, серверная авторизация, защищённый API и применение лимитов на стороне оператора.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Основные экраны находятся в `src/pages/`, демоданные — в `src/data.ts`, переводы — в `src/i18n.ts`.
